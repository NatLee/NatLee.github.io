# i18n rules

Hand-rolled i18n, no library. Two locales: `en` (default, fallback) and `zh-TW`.

- **UI strings** (nav, headings, terminal text): `messages/en.json` + `messages/zh-TW.json`. Any key added/changed/removed must be applied to BOTH files with identical structure. Components read them via `useLanguage()` → `t('dot.path', {var})` from `contexts/LanguageContext.tsx`.
- **Content translations**: `assets/data/i18n/{projects,experience,education}.zh.json` — partial overlays keyed by item id, merged at read time in `data/*.ts`. Missing fields fall back to English; never duplicate the full English object.
- Category display labels for zh live in `categoryLabelsZh` inside `data/projects.ts`, not in the overlay files.
- Locale persistence uses localStorage key `natlee-portfolio-locale`; default is `en` (deliberately not browser-detected).
